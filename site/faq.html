The basics

What is 4k7?

An all-in-one workbench for makers: AI-assisted PCB design and 3D enclosure design in one free app. You describe a project in a sentence; the agent asks what it needs to know, imports the parts from their datasheets, draws the schematic, lays out the board, designs the enclosure and prices the order. You review every change.

It is not meant for professional board designers. It is for everyone who wants to get from an idea to a working board, fast.

What does it cost?

4k7 is free and open source under the MIT license. It ships no AI model: you bring your own (next question), and that is billed by whoever provides it.

Which AI do I need?

Any of these:

  • a coding agent you already use, on the plan or company login you already have: Claude Code, GitHub Copilot CLI or OpenCode;
  • an API key: Anthropic, OpenAI, OpenRouter, Gemini, a local model, or any OpenAI- or Anthropic-compatible gateway;
  • or your agent's own chat, driving 4k7 through its MCP server.
Why “4k7”?

It is the value of a very common resistor, 4.7 kΩ. Its bands are yellow (4), violet (7), red (×100) and gold (±5 %), which are also the four steps of the app: schematic, board, enclosure, order.

Installing

What do I need?

A Mac (Apple silicon or Intel), a Windows PC (x64) or a Linux computer (x64 or arm64), and an AI as above. The download has Node inside, so there is nothing else to install.

Opening the app opens it in your browser. Closing the tab stops it.

Is there a Windows version?

Yes, for x64 PCs. Download the zip, unpack all of it and double-click 4k7.cmd. It is not signed yet, so Windows may say it protected your PC the first time: choose More info, then Run anyway.

It is new: so far it has run on GitHub's Windows test machines, not on a desktop PC, so tell us on GitHub how it goes. With Node 22.18+ you can also run it straight from the repository with npx github:hoihu/4k7.

macOS says it cannot check the app

The Mac app is not signed yet. Open System Settings → Privacy & Security and choose Open Anyway.

What does alpha mean?

Features, screens and the project file will keep changing between releases, sometimes a lot, and some things will break. The changelog says what changed; tell us what broke on GitHub.

Your work

Where are my projects, and can I leave?

Every project is a plain file on your computer, saved as you work. The outputs open anywhere: Gerber, drill, BOM and pick-and-place for the board, STEP for the 3D model, and 3MF or STL for the enclosure. The script it came from downloads too, but it runs only in 4k7.

Your API keys stay in your browser. Nothing is hosted: there is no 4k7 server that holds your designs.

How does it know a part?

From the manufacturer's datasheet. The agent reads the PDF, and you get the symbol, the land pattern and the pin functions. It designs from the datasheet's typical application and design procedure, and says which page each choice came from.

Can I trust what the agent does?

It works step by step and you review every change before it is kept. The drawings are checked on every change, and the enclosure is checked against the board and every plug. It is still an AI and alpha software: look at the result before you order anything.

Ordering

Which board houses does it know?

JLCPCB, PCBWay and Eurocircuits. 4k7 checks live stock for the number of boards you want, prices the assembly with every fee, and offers parts that are in stock or cheaper, a click away. The files for the board house come from the same project.
