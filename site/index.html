Direct Datasheet Part Import

Just tell the agent which part it should use (or let it propose one) and then it will automatically download the datasheet, extract the correct land pattern and the pin mapping, and create a 3D model as well. The datasheet stays beside the imported part, so you can look up details later on if needed. The agent can even read application guidelines from the datasheet, e.g. recommended layouts or reference implementations.

  • Symbol and land pattern from the PDF
  • Application notes, cited by page
  • Sheets that draw themselves, checked on every change

Intuitive Board Layout with amazing 2D / 3D views and artworks

Let the agent propose the best positions. Manually pin the positions of key components on the PCB. Then the agent does the rest for you. But this is not the end: Create artistic silkscreens on request! Why not add snowflakes for example? Or let the agent design crazy outlines of the PCB - why not a Christmas tree shape for your next project?

  • Placement and routing, to the last connection
  • Inner planes, pours, set impedance
  • Gerber, drill, BOM, pick-and-place, STEP

Fully integrated Enclosure design

With a few easy prompts, design a fitting enclosure for your PCB. Not only a simple box, but anything that belongs to your project, for example: a desktop holder, an optical waveguide, decorations on the lid etc. You can even do cuts along an axis to inspect details and margins. Or add reinforcement ribs with a simple additional prompt if the design is too weak. The agent has full control of the design using a scripted version of Manifold 3D, so there are almost no restrictions.

  • A JavaScript script you can read and edit
  • Checked against the board and every plug
  • 3MF print plate, or one STL per piece

Check against popular manufacturers before you make your final order

When ordering PCBs or assembled PCBAs, the surprise comes when you see the costs. Sometimes, easy adjustments to the design save a LOT of $$$. 4k7 gives you an overview of 3 popular manufacturing services and tries to summarize how much it would cost to produce the PCB. It's an approximation, but 4k7 is able to propose changes to designs if it makes sense.

  • Live stock and prices
  • Every assembly fee, itemised
  • Replacements and cheaper values in one click
